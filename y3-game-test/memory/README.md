# Y3 Game Test - Memory 记忆系统

此目录包含游戏测试的经验记忆，在开始测试工作前**必须阅读相关文件**。

## ⚠️ 重要说明

**Memory 文件需要用户根据实际项目情况自行维护！**

- 这些记忆文件是**模板和示例**，不是固定的规范
- 你需要根据自己项目的 API、流程、踩过的坑来修改和补充
- 每次遇到新问题/新经验，及时更新相关记忆文件
- 这是**活的文档**，越用越完善

## 📂 记忆文件索引

| 文件 | 必读级别 | 适用场景 |
|------|---------|---------|
| `main.md` | ⭐⭐⭐ **必读** | 每次测试工作开始前 |
| `skill-test.md` | ⭐⭐ 按需 | 测试 Lua 技能代码 |
| `ui-test.md` | ⭐⭐ 按需 | 测试 UI 模块 |
| `equip-test.md` | ⭐⭐ 按需 | 测试装备系统 |

## 🔄 工作流程

```
开始测试任务
    │
    ▼
阅读 main.md （必读！）
    │
    ▼
判断测试类型
    │
    ├─ 技能测试 → 阅读 skill-test.md
    ├─ UI 测试 → 阅读 ui-test.md
    ├─ 装备测试 → 阅读 equip-test.md
    └─ 其他 → 查看是否有相关记忆
    │
    ▼
执行测试
    │
    ▼
更新记忆（如有新经验）
```

## 📝 记忆更新规则

当遇到以下情况时，应更新相应的记忆文件：

1. **发现新的坑点** - 记录问题和解决方案
2. **找到更好的测试方法** - 更新模板代码
3. **API 变化** - 更新相关命令和代码
4. **常见错误** - 添加到常见问题列表
